## 方法论

PawBench 的 Model × Harness 视角提醒我们：Agent 分数由模型和运行框架共同产生。只比较“旧模型+旧 Harness”与“新模型+新 Harness”时，差异无法归因。本课固定任务集、环境快照、Rubric、重复轮次和工具依赖，构造 `M0H0、M1H0、M0H1、M1H1` 四格。模型差值分别在 H0/H1 下计算，Harness 差值分别在 M0/M1 下计算；两条模型差值之差是交互差值。交互不为零时，不能说某个模型在任何 Harness 下都更好。

输入来自同一个物理隔离评测集合的四个完整批次；Task 清单与哈希必须一致，按 `(task_id, repeat_index)` 配对。Code Evaluator 的结果与轨迹指标、成本和安全状态分别展示。安全违规一票否决仍由发布门禁执行；任何 `unknown` 不能记作安全通过。多次随机运行、置信区间、顺序随机化和环境漂移审计是正式能力结论所需条件。当前已有同题真实四格试点，但 Task 仍仅四道同类合成题，不能宣称生产对比成绩。

版本应同时记录模型实际 ID、Harness 提交或构建 ID、提示词、工具与环境快照；仅写 `m1/h1` 标签不够复现。保持同一评测流量标记和 Holdout 隔离，禁止根据四格结果反复调题造成污染。

## 面试考点与踩坑

- 问：只跑 M0H0 与 M1H1 能归因吗？答：不能，两个因素同时变化。
- 问：模型差值在两个 Harness 下不同意味着什么？答：存在交互，模型效果依赖编排环境；先检查提示词、工具契约和调度差异。
- 问：交互差值等于零就证明无交互吗？答：小样本的观测值为零不等于总体无交互，需要重复试验与不确定性分析。
- 坑：四格任务快照或评测器版本不同会制造伪差异；运行顺序与外部服务漂移也会混淆结论。
