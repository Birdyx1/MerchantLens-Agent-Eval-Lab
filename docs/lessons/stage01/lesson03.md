# 1.3 Trace 追加写入

状态：已通过（参考示例后手写）。

[阶段文档](README.md) · [总计划](../../plan.md)

建议用时：15—25 分钟。目标：将单条 Span 追加写入 JSONL 文件。

## 知识点

JSONL 的每一行都是一个独立 JSON 值。每产生一条 Span 就追加一行，后续可以逐行读取；这是本项目的本地存储约定，不是 OTLP 格式。

## 实践任务

创建 `src/merchant_agent/tracing/writer.py`，自行实现函数：

```python
def append_span(path: str, span: dict) -> None:
    ...
```

函数将 `span` 序列化为一行 JSON，并以 UTF-8 追加到 `path`；父目录不存在时创建。可使用 Python 标准库 `json` 和 `pathlib`。

使用第一课 `fixtures/traces/basic.json` 的两条记录手动调用函数，验证两次写入后的内容。使用临时路径，避免覆盖已有数据。

## 验收标准

1. 写入两条 Span 后文件恰有两行，每行能用 `json.loads` 解析并还原输入。
2. 文件已存在时再次写入不会覆盖原有行；不存在的父目录能够创建。
3. 字符串内的换行、中文能正确序列化并还原。
4. 输入不能序列化或文件无法写入时，错误应传给调用方，不伪装成成功。

## 面试考点与踩坑

- JSONL 与 JSON 数组的区别：一行一条记录，支持逐行处理。
- 字符串中的换行需由 JSON 序列化器转义，不能手动拼接内容。
- 本课只验证单进程的基本追加，不声称支持并发写入、崩溃恢复或 Schema 校验。
