## 知识点

轨迹重建是读取过去记录下来的运行过程，用于检查 Agent 做过什么；重新执行 Agent 则会再次运行模型或工具，结果可能变化。本课先练习前者的第一步：读取 Span。

第三课的写入器把每条 Span 保存为 JSONL 中的一行。注意，`fixtures/traces/retry.json` 是 JSON 数组，不是 JSONL 文件。

## 实践任务

创建 `src/merchant_agent/tracing/reader.py`，自行实现：

```python
def read_spans(path: str) -> list[dict]:
    ...
```

读取 UTF-8 JSONL，按文件顺序逐行解析，返回 Span 列表。输入约定：有效文件中每行是一个 JSON 对象，空文件表示没有记录；空行视为格式错误。使用 Python 标准库即可。

练习时，可使用第三课的 `append_span` 将 `retry.json` 的三条记录写入临时 JSONL，再用新函数读取。不要覆盖或修改原始样本。

## 验收标准

1. 读取三条有效记录，返回列表内容与写入数据相同、顺序一致。
2. 空文件返回 `[]`；中文及字符串内的换行能正确还原。
3. 文件不存在时向调用方抛出文件异常；无效 JSON 或空行时抛出解析异常，不静默跳过。
4. 返回的数据不因读取操作而改变原文件；本课不要求 Schema 校验或调用 Agent。

## 面试考点与踩坑

- JSONL 是一行一条 JSON，不应把整个文件当作单个 JSON 数组解析。
- 使用 JSON 解析器还原转义的字符串；不要自行按逗号拆分内容。
- 能读取历史轨迹不等于能复现模型输出或外部工具状态。
