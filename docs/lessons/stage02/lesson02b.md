建议用时：20—30 分钟。目标：查询指定门店的净支付金额。

## 知识点

连接 SQLite 时指定 `mode=ro` 和 `uri=True` 可以只读打开已有数据库；路径不存在时不会静默创建。SQL 参数应使用 `?` 占位符绑定，而不是拼接输入。[Python sqlite3 官方文档](https://docs.python.org/3/library/sqlite3.html#how-to-work-with-sqlite-uris)

只读连接是本课数据库文件的保护措施。租户授权、任意 SQL 安全、超时和资源限制不在本课完成范围。

## 实践任务

创建 `src/merchant_agent/tools/sql/sql_query.py`，实现：

```python
def get_store_net(db_path: str, store_id: str) -> int | None:
    ...
```

函数以只读模式打开数据库，执行固定的门店净支付聚合查询，使用 `?` 绑定 store_id，并关闭连接。匹配订单时返回金额（整数分）；没有匹配订单时返回 None。查询或连接出错时将异常传给调用方。

提示：`Path(db_path).resolve().as_uri()` 可将路径转换为文件 URI，在其后添加 `?mode=ro`；`fetchone()` 返回一行元组，聚合值在第 0 项。仅需 Python 标准库。

## 验收标准

1. 对上一课初始化的数据，A 返回 12000，B 返回 8000；不存在的门店返回 None。
2. 使用参数绑定，包含 SQL 注入文本的 store_id 被当作普通字符串，不能改变查询逻辑。
3. 使用 SQLite 只读 URI；数据库文件不存在时抛错且不创建文件。正常与异常路径都释放已创建的连接。
4. 查询后数据库内容不变；练习与验证使用临时数据库。

## 面试考点与踩坑

- 只读连接限制数据库写入；参数化查询让传入的门店 ID 作为值处理，两者各有作用。
- `SUM` 在没有匹配行时返回 NULL，对应 Python 的 None；不能误认为一定是 0。
- `with sqlite3.connect(...)` 管理事务，但不会自动关闭连接，需显式关闭或使用 closing。
- 这个函数只提供固定的业务查询，尚未成为可执行任意 SQL 的 MCP 工具。
