## 知识点

Agent 传入的 Python 代码可能报错、无限运行或访问外部资源。工具入口需要检查参数；真正的执行还需要隔离环境和资源限制。**参数校验本身不是沙箱。**

本课的 1—5 秒是学习用的项目约定，后续可以按任务和运行环境调整。

## 实践任务

创建 `src/merchant_agent/tools/python_sandbox/python_request.py`，实现：

```python
def validate_python_request(code: str, timeout_seconds: int) -> None:
    ...
```

要求：`code` 必须是包含非空白内容的字符串；`timeout_seconds` 必须是 1 至 5（含边界）的整数，不能是布尔值。输入无效时抛出 `ValueError`，有效时返回 None。本课不运行传入的代码。

## 验收标准

1. 非空代码和 1、5 秒均通过，返回 None。
2. 空字符串、只有空格或非字符串代码抛出 ValueError。
3. 超时为 0、6、浮点数或布尔值时抛出 ValueError。
4. 对 `import os` 等非空字符串，本函数只检查参数，不声称它是安全代码，也不执行它。

## 面试考点与踩坑

- Python 中 `bool` 是 `int` 的子类，使用 `isinstance(value, int)` 时需要单独考虑布尔值。
- 输入检查、超时参数和真正的进程隔离分别解决不同问题；不能用过滤危险关键字充当安全沙箱。
