## 知识点

真实搜索结果会随时间和网络变化。用固定模拟数据测试，可以复现相同输入下的结果，用于检查 Agent 是否正确处理工具输出。本课的匹配规则只是测试约定，不能代表真实搜索质量。

## 实践任务

在 `src/merchant_agent/tools/search/fake_search.py` 中实现 `FakeSearchProvider`：

- 构造时接收 `results: list[SearchResult]` 作为模拟数据。
- 提供 `search(self, query: str, limit: int) -> list[SearchResult]`。
- `query` 必须是去除首尾空白后非空的字符串；`limit` 必须是 1 到 10 的整数，不接受布尔值。无效输入抛 `ValueError`。
- 把处理后的查询词与每条结果的 `title` 或 `snippet` 做忽略大小写的子串匹配；保持原顺序，最多返回 `limit` 条，没有匹配时返回空列表。

提示：可使用字符串的 `strip()` 和 `casefold()`。无需访问网络，也无需显式继承 `SearchProvider`。

## 验收标准

1. 使用模拟结果检查标题匹配、摘要匹配、大小写、前后空白、排序与数量上限。
2. 无匹配返回 `[]`；空查询、非字符串查询、布尔值及越界数量抛 `ValueError`。
3. 返回列表中的元素是原有 `SearchResult`；不依赖真实检索服务。

## 面试考点与踩坑

- 固定模拟数据让测试可复现，但不能替代真实服务的集成测试。
- `bool` 是 Python 中 `int` 的子类，校验数量时要单独排除。
- 搜索摘要只是线索，后续仍需验证来源；模拟数据不能当线上证据。
