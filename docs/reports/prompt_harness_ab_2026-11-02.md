# G 题规划提示词 Harness 对照（2026-11-02）

## 问题与设计

先前 G 题一次重复 Trial 中，SQL 成功返回后，模型直接输出自然语言，违反规划节点 JSON 契约。实验固定已仲裁的 G Task、订单快照、DeepSeek `deepseek-flash`、MCP 工具、评分器源码和 Agent 图；只改变系统规划提示词。基线为原提示词，候选增加“工具观察后也必须以同一 JSON 结构返回、最终答案放在 `action.type=finish` 中”的提醒。提示词 SHA-256 与源码摘要冻结于私有记录 `runs/prompt_harness/94bca325619e49228e1d065aefd74ee4/experiment.json`。

每个版本运行 5 次，同一轮次成对比较，顺序在 AB 与 BA 之间交替。10 条 Trial 均保留原始 Trace，实际模型 Span 的模型 ID 均为 `deepseek-flash`；Holdout 未参与。模型接口未固定随机种子，因此配对和交替只能减少部分时间漂移，不能完全控制随机性。

## 归因与下一步

先前失败 Trace 支持“模型输出未满足 JSON 契约”的局部归因，但该行为可能是低频随机事件。更可靠的改进需要预注册更多任务和轮次、考虑模型接口的结构化输出能力、分别观察合规率与最终业务成功率，并把增加的 token 成本纳入门槛。若修改解析器容错或重试策略，应作为另一项 Harness 变量单独实验，不能混入本次提示词对照。
