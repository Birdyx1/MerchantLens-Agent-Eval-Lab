# BFCL / BIRD 固定子集实验结论

2026-11-03，固定 40 道公开题目，每题每配置重复 3 次，共完成 240 个 Trial。

| 子集 / 配置 | 成功 / Trial | 成功率 | 每题三次均成功 | 平均耗时 | 平均 Token（观测数） |
|---|---:|---:|---:|---:|---:|
| BFCL / DeepSeek | 53/60 | 88.3% | 17/20 | 1.26 s | 468（60） |
| BFCL / GLM | 49/60 | 81.7% | 15/20 | 5.13 s | 539（60） |
| BIRD / DeepSeek direct | 22/60 | 36.7% | 6/20 | 5.68 s | 1,472（51） |
| BIRD / DeepSeek react | 17/60 | 28.3% | 2/20 | 5.68 s | 2,527（53） |

实际模型标识为 `deepseek-flash` 与 `zai-org/GLM-5.3-Flash`。BFCL 使用统一 JSON prompting，复用官方 Python 评分函数；BIRD 使用官方 EX 结果行集合比较。此为项目适配的公开基准子集实验，不是官方全量榜单成绩。

## 结果解释

1. BFCL 的 simple_python 与 parallel 在两模型下均为 15/15；主要差异集中在 irrelevance：DeepSeek 9/15，GLM 5/15。GLM−DeepSeek 的配对差值为 −6.7 个百分点，按题目 Bootstrap 95% 区间为 [−20.0, +3.3] 个百分点，包含 0，不能宣称稳定优劣。
2. BIRD react−direct 为 −8.3 个百分点，区间 [−30.0, +11.7]，包含 0。本次未观察到 ReAct 配置的成功率收益。每题三次均成功分别为 6/20 与 2/20，至少一次成功分别为 9/20 与 10/20，说明“偶尔做对”和“重复稳定做对”不同。
3. 格式协议是 ReAct 的主要失败来源：60 次中有 20 次输出夹带解释、多个 JSON 对象等，违反单对象协议；另有 14 次结果不匹配、2 次耗尽步数、7 次响应或适配异常。下一步应优先检查结构化输出与工具交互协议，但尚不能断言修复后一定提升。
4. ReAct 平均模型调用 1.78 次、工具查询 0.82 次，直接生成 SQL 为 1 次模型调用、无工具查询。Token 均值仅覆盖用量可观测的完整响应 Trial，不能把缺失用量当零成本，也不能直接换算为跨厂商货币费用。

## 可复核的失败

- `irrelevance_60` 未提供商品原价，GLM 部分输出自行填入 `price=100` 后调用价格工具，按官方标签记为不应调用。这与经营查询中“缺少门店编号时不猜参数”的风险相近。
- `irrelevance_109` 要求计算营养需求，而工具用于浇水量；GLM 三次均选择该工具。
- `multiple_25` 中两个模型各有一次输出多个调用，官方 multiple 类别的期望调用数量不符。评分依据固定官方规则，不将所有“多工具”题都解释为“应并行调用多个工具”。
- `bird_388`、`bird_482`、`bird_338` 的部分 ReAct 输出在 JSON 后继续生成解释或额外对象，触发格式失败；原输出保存在对应 Trial 文件。

## 观测缺口与范围

16 次错误均发生在模型适配层返回有效 ModelResponse 之前，只保留了 `ValueError` 类型，未保留原始 HTTP 响应或详细错误消息。无法进一步区分响应未完成、截断或其他响应契约问题，不将其称为网络故障，也不从成功率分母删除。下一批应在脱敏后记录响应状态与归一化错误原因。

BIRD 只选五个较小数据库，存在数据库选择偏差；BFCL 只含四种单轮类别，不代表多轮或 Agentic 总分。两模型接口及 thinking 配置不同，不能将差异归因于模型权重本身。ReAct 是实验专用的受限 SQL 循环，未评价完整 LangGraph 系统或原生 tool calling。

公开开发题不等于密封 Holdout；没有真人双标，也未据此宣称生产表现。重复运行有随机性，固定输入和记录可复算不代表模型输出能逐字复现。

## 验证与复现

- 仓库全量测试：**407 passed**。
- 离线审计：240 个计划 Trial 全部核对；224 个可评分 Trial 用冻结官方函数重算一致；16 个错误 Trial 原样保留，未重新请求模型。
- 所有来源文件及 SQLite 文件在运行前后哈希一致，未使用项目 Holdout。
