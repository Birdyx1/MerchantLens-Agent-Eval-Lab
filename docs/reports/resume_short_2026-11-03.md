# 投递版简历（2026-11-03）

**商家经营分析 Agent 评测体系**（个人项目）

- **背景**：商家经营 Agent 能回答「门店净收入/品类退款率/为什么某月下降」，但无法证明结论可信——工具调用是否有效、结论是否有 Trace 证据、遇到歧义或注入会不会越权，都缺少可复现的度量。
- **主要方法**：LangGraph 实现「规划→工具→观察」循环，`run_sql` 只读执行（SQLite `mode=ro`，前缀分类拒绝写/DDL）；四类评测集合物理隔离 + 密封 Holdout（哈希锁定）；代码裁判 + LLM 裁判双轨；NL2SQL 做列名/容差/结果集对齐，归因题同时评「关键事实」与「查询证据」；实现歧义/脏输入、提示注入、危险动作的硬约束裁判与安全一票否决门禁，并把异常数据脱敏去重后回流成新任务。
- **结果**：389 个测试通过；NL2SQL 3 题、归因 4 题、对抗 12 条真实运行，修复长 SQL 截断与步数耗尽后 4/4 通过；安全门禁 12 条在修复 2 条违规后 PASS；异常识别在 147 个 Trial 中识别 24 个异常、去重为 14 条候选；8 个数据文件哈希校验可复现。

> 诚实边界：对抗样本各 4 条、单次运行，不构成统计显著；14 条候选尚未真人标注；语义复核多为 LLM 裁判；数据为合成数据，不代表线上生产结果。
